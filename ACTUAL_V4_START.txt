柴田屋OZ — 実績管理 v4 自宅Wi-Fi確認用

確認済みv3をコピーし、必要箇所だけを追加した完全ソース一式です。
GitHubへのアップロードは不要です。実患者データは入力しないでください。

1. 起動中の旧テストは、そのPowerShellで Ctrl+C を押して終了。
2. ZIPを新しいフォルダー OZ_Home_Actual_v4 に解凍。v3は残します。
3. 解凍先を開き、その場所で通常のPowerShellを開く。
4. 同じウィンドウで以下を順番に実行。

Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
Unblock-File -LiteralPath '.\browser-tests\Run-iPhone-Home-Test.ps1'
.\browser-tests\Run-iPhone-Home-Test.ps1 -WifiAddress '192.168.24.28'

Wi-FiのIPが変わった場合は現在のPCのWi-Fiアドレスを指定します。
ビルド後、その回の /pair/ を含むURLをPC・iPhoneで開きます。
画面下部「実績検証 v4」を確認。古いURLは使いません。
20分で自動終了。再起動時に架空データは初期状態へ戻ります。

操作確認
1. 架空患者を予約し、予約カードをタップ。
2. 「来院記録」 → カードに来院表示。
3. 再度開いて「実施記録」 → 確認して保存。
4. 予約表下の「履歴を表示・更新」 → 来院・実施済の2行。
   各行は記録履歴であり、人数の集計ではありません。
5. 別の予約で「キャンセル記録」 → 枠が空き、履歴が残る。
6. 実施記録を付けた予約を「予約解除」しても履歴が残る。
7. PC・iPhone双方の表示と同時変更時の中央競合通知を確認。

実施・未実施・キャンセル確定後の訂正操作はまだありません。
誤入力訂正、Excel列マッピング、人数集計、日報は次工程です。
患者設定は予約の分類・メモを変更する既存仕様を維持。
今回の実機確認結果を頂くまで本番完成・Golden Master昇格とは扱いません。
実行制御でブロックされた場合は保護設定を解除せずエラーを送ってください。
