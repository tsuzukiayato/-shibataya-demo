柴田屋OZ v1.7 COMPLETE - GitHub Pages用完全版

アップロード方法:
このZIPを解凍し、index.html を含む中身をGitHubリポジトリのルートへアップロードしてください。
GitHub Pagesは index.html を自動表示します。

統合機能:
・PT別予約表（20分単位）
・20/40分予約、同一患者番号の同日重複防止
・予約カードのドラッグ移動（サイズ固定）
・予約カードから20/40分変更、患者詳細、予約削除
・20分枠ごとの通常/物療/閉鎖/シフトへ戻す
・1か月シフト作成→予約表自動反映
・患者登録/検索/編集
・一般/赤まとめ/青介護（青は20分固定）
・患者ごとの固定曜日/時間/PT
・本日の予約表
・来院/取消ステータス
・予約データから日報プレビュー自動集計

重要: 現在はデモ版です。実患者の氏名・患者番号・診療情報は入力しないでください。
